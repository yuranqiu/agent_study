# 论文笔记

> 按主题/论文名组织。每个笔记文件命名：`YYYY-MM-DD_paper-name_summary.md`

## 笔记规范

每个笔记文件包含：
1. **基本信息**：论文标题、作者、会议/期刊、链接
2. **一句话总结**：这篇论文解决了什么问题，核心方法是什么
3. **核心方法**：用流程图或示意图说明（ASCII 或文字描述）
4. **关键创新点**：2-3 条
5. **代码/实现细节**：如果有开源代码的位置
6. **面试相关**：这篇论文可能被问到的面试题
7. **疑问/思考**：读完后还有哪些不清楚的地方
